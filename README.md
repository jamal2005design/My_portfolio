# Portfolio Website

A modern, responsive portfolio website showcasing professional skills, projects, and experience. Built with clean design and smooth animations for optimal viewing across all devices.

## About

This portfolio website features:
- Professional introduction with profile picture
- Technical skills and competencies display
- Project showcase with detailed descriptions
- Educational background and achievements
- Contact information and direct communication options

## Technology Stack

Built using modern web technologies including HTML5, CSS3, and JavaScript with responsive design principles.
